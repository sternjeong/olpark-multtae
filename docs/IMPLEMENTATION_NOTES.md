## 2. 명세에서 바꾼 것(최소 변경)
1. **만조 돌출도 정의**: "양쪽 90분 안 최소값과의 차"를 90분 창으로 그대로 구현하면 토요일 최고점(15:20)이 바로 옆의 비슷한 봉우리(16:40) 때문에 탈락하고 낮은 11:00만 남았습니다. 표준 지형 돌출도(양쪽으로 자기보다 높은 지점까지의 최소값 중 큰 쪽과의 차)로 바꾸고, "서로 90분 이상 떨어짐" 조건은 유지했습니다. 파라미터는 `profiles.json.tide_rules`에 기록하고 JS·Python이 같은 값을 씁니다.
2. **저장소 구조**: 지시에 따라 원본 CSV를 `data/raw/{id}/{id}_1.csv`(바이트 그대로, 13종 약 16MB)로 두었습니다(명세의 `snapshot/raw/*.csv.gz` 대신). `manifest.json`도 `data/raw/`에 있습니다. 중간 산출 `work/norm/*.json`은 만들지 않고 메모리에서 처리합니다.
3. **JS 모듈 구성**: 첫 화면 요청 수 예산(≤10)을 지키려고 홈에 필요한 코드(라우터·데이터·모델·차트·시트·사리·실시간 카드·ics)를 `app.js` 하나에 두고 `views/week.js · livepage.js · method.js · org.js`를 지연 로드합니다. `classes.json`(시트를 열 때)·`events.json`(사리 패널을 열 때)도 지연 로드합니다. 첫 화면 요청: HTML·CSS·JS·JSON 5개·실시간 API = 9개.
4. **큰 글씨**: 명세 안에서 값이 엇갈려(F15 112.5→125%, §13.3 18→20px) 기본 100% → 큰 글씨 125%로 했습니다.
5. **재현 명령**: 기관용 카드의 재현 명령은 이 저장소 안에서 실행되는 `python3 -m build.quality --check Qxx`입니다(탐색 스크립트 경로는 이 저장소에 없음).
6. **사리 Δ의 기준**: 주말 프로파일은 평활된 값을 쓰므로 Δ = 행사일 원값 − 평활 프로파일입니다(그래야 7월·시작 시각 그대로일 때 F_sari가 행사일 원값과 같아짐).
7. **상황 칩의 공지 2개 고르기**: 명세에 순서 규칙이 없어 "주차·회차·차량·출입·대중교통" 제목 우선 → 게시 시작일 순으로 정했습니다.
8. **시트 강좌 목록 창**: S_d(k) 식과 맞도록 시작 구간이 k+1~k+3인 강좌(구간 시작 기준 10~49분 뒤)를 보여 줍니다.
9. **주간표 붐빔 막대**: 11월 7일 모두 기간 최대의 75% 이상이라 4단계가 같게 나와, 막대 아래에 "최대 약 N대"를 함께 적었습니다.
10. **404.html**: GitHub Pages는 깊은 경로에서도 404.html을 주므로, `*.github.io`에서는 첫 경로 조각(`/olpark-multtae/`)을 기준으로 되돌아갑니다. JS가 없으면 `./#/` 링크가 보입니다.
11. **PWA(F17, 선택)**: 만들지 않았습니다. 오프라인 배너(navigator.onLine)만 있습니다.

## 3. 확인한 사실과 비활성 처리
- **공휴일(2026-11 ~ 2028-12)**: 한국천문연구원 천문우주정보 달력자료(월력요항) 페이지(`astro.kasi.re.kr/kor/life/post/calendarData?search_year=YYYY`)의 '국경일과 공휴일' 표에서 옮겼습니다(2026-11-15 조회). 2027년은 2026-06 발표된 공식 월력요항 기준(노동절·제헌절 공휴일과 대체공휴일 포함), **2028년은 '공식 발표 전' 잠정 자료**로 `holidays.json.status`에 표시했습니다. 2027-06 월력요항 발표 뒤 대조가 필요합니다. 선거일 외 임시공휴일은 들어 있지 않습니다.
- **기상청 격자(방이동)**: 기상청 Open API 활용가이드의 LCC 변환식으로 올림픽공원(37.5206, 127.1214) → nx=62, ny=126을 계산했습니다(같은 식이 서울시청에 대해 알려진 값 60,127을 냄). 격자 엑셀 대조는 하지 못해 `build/config.py`에 TODO로 남겼습니다. 이 어댑터는 `DATA_GO_KR_KEY`가 있을 때만 돌고, 키가 없으면 날씨 칩은 숨겨져 화면에 영향이 없습니다.
- **문화공공데이터광장(KCISA)**: 엔드포인트를 확인하지 못해 `build/static/kcisa_endpoints.json`을 비워 두었고 어댑터는 건너뜁니다. 공연은 사용자 입력 시나리오로 동작합니다.
- **포털 무키 다운로드**: `build/fetch.py`로 15143220·15131671을 실제로 받아 스냅숏과 바이트가 같음을 확인했습니다(2026-11-15).
- **실시간 API**: 브라우저(헤드리스 Chromium)에서 CORS로 직접 호출 성공, `build.live collect`로 1회 수집 성공(2026-11-15 11:15 KST 2,099대 — 저장소에는 넣지 않음, 아카이브는 Actions가 `archive` 브랜치에 쌓음).
